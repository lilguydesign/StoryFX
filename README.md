# StoryFX

Le chantier Internet ajoute un serveur Python, un dashboard web et un agent
Android natif. Le premier jalon fonctionne uniquement avec des diagnostics
synthétiques : aucune Story ou campagne n'est activée.

Lire [le guide du chantier](README.internet.md) pour l'installation, les tests,
l'architecture retenue et les étapes vers le fonctionnement autonome.
